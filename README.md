# Générateur Alerte Info

Outil web pour créer des visuels d’actualité aux formats Facebook, Instagram et statut WhatsApp : huit modèles (Alerte, Bandeau, Une, Citation, Chiffre, Surligné, Duo, Dossier), identité du média, légende prête à copier et export JPG en 1080 px.

Tout se passe dans le navigateur : les photos et les textes ne quittent pas l’appareil.

Site : https://togoimy-hassane.github.io/alerte-info/
